# GPU replacement for the CPU torch pin in requirements.txt (P0-06).
#
# The base requirements (requirements.txt) always pin the CPU torch wheel,
# so a clean environment and CI never depend on a CUDA wheel.  Machines
# with an NVIDIA GPU replace the torch pin with the CUDA wheel of the
# SAME base version:
#
#     pip install -r requirements-cuda.txt
#
# then run with --device auto (CUDA when available).  Keep the torch base
# version here in sync with requirements.in's torch; freeze_lock --check
# verifies this file's consistency on every CI run.
#
# This file is hand-maintained (machine-specific by design) and is NOT
# generated by scripts/freeze_lock.py.
--extra-index-url https://download.pytorch.org/whl/cu128
torch==2.11.0+cu128
