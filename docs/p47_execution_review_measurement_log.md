## 3 冻结裁决（§6 逐条）

1. **触发**：动态规则未优于首次建仓持有（4 臂中 3 臂劣于 hold；
   组合臂 −28.9pp/−1.7pp）→ **停止把当前结果解释为"十日动态选股
   有效"**。R03 的 `equal_weight_stands` 解释在本帧被取代：其正超额
   不在修正口径 + 今日方向身份下复现。
2. 本帧超额为负；损失主因是**机制性现金暴露**（priority 清算病理，
   exposure −29.5pp 主导）——记录为执行规则缺陷而非配置机会；
   p44 修订（退出/进入预算分账）登记为后续工程项，配置问题研究不
   开启。
3. **触发**：执行恢复（订单可成交）后净空间不只是消失而为强负
   →记录：成本二阶（≤1.6pp），主因是**预算×节奏×规则交互的清算
   病理 + 信号不足**（hold 口径选股 ≈ 0）。
4. 不触发：无稳定增量 → **不开放小规模搜索对照**（搜索预算维持
   冻结）。
- P39 边界维持：本轮未做周期比较；n20 的相对改善不外推为持仓数或
  周期结论。
