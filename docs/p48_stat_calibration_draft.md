## 2 冻结语义（实现必须逐条可对照）

**B1 统计量规格声明**（声明现行权威，零语义改动）：
- **主统计量 max-t**（p40/p43 现行实现 `max_t_from_matrix`）：
  观察统计量 = 被裁决试验在窗口 W 上的学生化均值
  `√n·mean/std`（Hansen-SPA 形）；零分布 = 联合矩阵全部列的
  学生化循环块 bootstrap 均值的 max；每次置换抽取**一条共享日期块
  索引**施加于所有试验；有效块长 `b = max(1, min(block_size, n//6))`；
  `p = (count+1)/(n_perms+1)`；拒绝判据 `p ≤ 0.05`。
  **适用样本范围**：`n_dates ≥ 30`（P40 下限，低于即拒绝）、
  `k ≥ 1`、矩阵有限（p43）、`n_perms ≥ n_perms_floor(0.05)=19`
  （低于则 p 格点达不到 0.05，判"无法作可靠推断"）。
- **副统计量 DSR**（B&LdP 解析式）：参数式闭式概率，其性质是解析
  声明而非重采样对象；本包不校准、不改（登记为后续可选校准项）。
  晋级门 G2 的绑定输入是 max-t，本包校准即覆盖晋级口径。

**B2 场景族（五类 + 功效两点，全部零均值原假设除功效外）**：
| 场景 | 生成 | 目标 |
|---|---|---|
| S1 独立噪声 | iid N(0,1)×0.01，k=8, n=250 | 尺寸 |
| S2 共同市场因子 | 0.95 载荷因子 + idio，k=8, n=250 | 尺寸（截面相关） |
| S3 自相关 | 逐试验 AR(1) φ=0.4，k=8, n=250 | 尺寸（序列相关） |
| S4 重复候选 | 3 独立噪声 ×3 复制，n=250 | 尺寸（多重性） |
| S5 短窗口 | n=30（P40 下限），k=4 | 尺寸（下限点） |
| P1/P2 功效 | 单试验日 SR 0.5 / 0.25，k=8, n=250 | 检测率 |

**B3 种子纪律（不可违反）**：校准种子块 `900000+`（校准专用），
与 C1–C5 的调整参与块（10000–50000）**显式不相交**并在注册表中
钉住。冻结规则：任何未来统计方法改动 → 必须启用新的不相交种子块
重新校准，旧块不得复用为验收。

**B4 判定规则（冻结，禁止放宽）**：对每个尺寸场景，R 次重复的拒绝率
配 Wilson 95% 置信区间：
- `CI 包含 0.05` → `calibrated`；
- `CI_high < 0.05` → `conservative`（有效尺寸低于名义，披露，合法但
  功效受损）；
- `CI_low > 0.05` → `unreliable_at_nominal`（**方法在该场景不控制
  名义 5%**——不得作 5% 显著性声明；诚实输出为实测有效尺寸与区间）；
- `R < 500`，或 `CI 宽度 > 0.04` **且区间不确定**（跨越名义水平）→
  `insufficient_samples`（**无法作可靠推断**）。（勘误 1，测量前由
  单测暴露的规则交互：整体落在名义一侧的区间本身就是 95% 置信的
  单侧裁定，其宽度不削弱该裁定；原"宽度>0.04 一律判不足"会把
  明确超标的场景误判为不可判。本勘误只增强"不得放宽"性质。）
功效场景：检测率 + Wilson 区间，无"通过"带（报告事实）。
**本包不得以任何形式调整带宽使未校准方法变"通过"**；若场景判
`unreliable_at_nominal`，唯一出路是修方法 + 新种子块重校准（另立
契约），不是改判据。

**B5 消费口径（gate-facing）**：`significance_readiness(calibrations)`
汇总：哪些场景可作名义 5% 声明、哪些不可；未覆盖场景一律
"无法作可靠推断"。此函数是显著性/晋级声明的**前置查询面**（接线
到声明流程属后续语义变更，本包提供权威）。

**B6 单元测试边界（轻量）**：只保结构不变量与小样本反例——Wilson
区间手算、判定逻辑表、`n_perms=18` 反例（任何数据都无法拒绝：
`1/19 > 0.05`，用巨大植入信号钉住）、种子块不相交、场景生成器性质
（因子载荷相关 ≈0.95、AR(1) lag-1 ≈φ、重复行恒等、n=30）。重校准
（R=1000 级）是独立验收任务，不进单测。
