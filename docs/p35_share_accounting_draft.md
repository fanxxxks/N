## 1 问题陈述（已实证）

回测引擎（`ashare_model/backtest.py`）逐会话迭代；非调仓会话
（`rebalance_due=False`）时构造器原样返回 prev 权重
（`constructor.py:233-235`），引擎以 `dot(冻结权重, o2o 调整收益)` 计利并把
冻结权重继续传给后续构造——等效于**每日零成本再平衡回最近目标权重**：
- 无交易期间持仓「股数」并不守恒（权重被冻结 = 隐性持续调平）；
- 调仓日的订单从冻结权重而非真实当前持仓推导（多日价格离散下订单量错误）；
- 权重和 < 1 时未投资部分按组合收益率复利（现金拖尾被吞）。

## 2 数学定义（冻结；实现必须逐条可对照）

**状态**：股票份额 s（raw 股数）、现金 C、权益
E = C + Σ_i s_i × p_i（p = 执行时点 raw 开盘价）；权重视角
w_i = s_i p_i / E，w_cash = C / E，Σw = 1。

**非调仓会话**（无执行）：每股票毛收益 r_i = 调整 o2o（现有 target_ret 语义，
含分红拆股的总回报口径，p19 §2）；组合毛收益 R = Σ w_i r_i（现金权重 r=0，
已正确计入现金拖尾）；净收益 net = R（无成本）。状态演化：
- E ← E × (1 + R)；
- **权重漂移**：w_i ← w_i (1 + r_i) / (1 + R)，w_cash ← w_cash / (1 + R)。
- 不变量 II（无交易）：股数守恒 ⟺ 上式漂移（调整价格下二者数学等价）；
  份额视角 s 不变、权重随价格漂移。

**调仓会话**（执行）：
1. 构造器接收**漂移后**的 w 作为 prev（阈值/最小额/换手预算/现金边界等全部
   既有抑制语义自动作用于真实当前持仓）；产出目标权重 w*。
2. **股数级执行**（raw 开盘价 p_i，整手 lot = 100 股）：
   - 买单：Δs_i = floor((w*_i − w_i) E / p_i / 100) × 100，向下取整，残差留现金；
   - 卖单（部分减仓）：Δs_i = floor((w_i − w*_i) E / p_i / 100) × 100（向下），
     残量继续持有；清仓（w*_i = 0）全数卖出；
   - 卖出受限/停牌：构造器已将 w*_i 保持为 w_i（零订单）——股数转换不得
     卖出被禁名字；
   - 买入受现金边界约束（floor 向下不会超支）。
3. **费用**：成本模型作用于**实际成交**名义额（买/卖各自、含每单最低佣金），
   从现金扣除；成本占比 cost_fraction = 费用 / E（会话净收益口径不变）。
4. **对账恒等式（不变量 IV）**：E_after = C_after + Σ s'_i p_i，且
   E_after = E_before − fees；逐执行时点成立。
5. 状态更新：s ← s'，C ← C'，w ← s' p / E_after（含现金权重），E ← E_after；
   随后该会话净收益按漂移口径计（净 = R_post − cost_fraction）。

**不变量 I（往返归一）**：零费用下两股票往返（价格回到起点）期末净值精确
回到 1（数值容差 1e−12）；含费用时回到 1 − 手算费用。
**不变量 III（订单来源）**：调仓订单名义额 = (w* − w_drift) × E；冻结权重
bug 存在时该量不同（RED 断言旧实现失败）。
**不变量 V（复权/公司行为边界）**：持有期内 2:1 拆股（raw 价减半）经调整
收益漂移对权重中性；下一次执行按当前 raw 价重推股数，与持有人实际头寸一致。

**范围边界（显式声明）**：本包不改变收益的调整口径（p19 总回报语义不变，
唯一语义变化 = 冻结权重 → 漂移权重 + 股数级执行）；不引入滑点模型变化、
不改变成本模型公式、不做 R02。

- **R-B 无交易漂移**：两股票、非调仓会话序列 → 权重按 §2 漂移公式逐日等于
  手算值；股数（份额视角）不变。旧实现权重冻结 → 失败。
- **R-C 订单来源**：先走出价格离散使 w_drift ≠ 最近目标，再触发调仓 →
  成交名义额 == (w* − w_drift) × E（手算），旧实现（冻结 prev）订单不同。
- **R-D 对账恒等式**：每次执行时点 C + Σ s p == E − fees（手算费用含最低
  佣金），全程成立。
- **R-E 边界**：卖出受限名字保持漂移权重不被强制卖出；2:1 拆股会话漂移
